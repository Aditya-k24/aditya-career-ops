---
name: Form answer style
description: How to write job application form answers for Aditya
type: feedback
---

Always write form answers as plain text with no em-dashes (--), no blockquotes, no markdown formatting. Keep answers short and direct.

**Why:** User pastes into web forms; markdown and em-dashes are hard to paste and look bad in form fields.

**How to apply:** Strip all em-dashes (replace with comma or period), no bullet point blocks, 3-5 sentences max per answer unless the field clearly calls for more.
