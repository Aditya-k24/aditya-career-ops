Auditable, tunable matches are the default in how I build.

  \item \textbf{Production Java and Python.} At Isomer AI I shipped 10+ features end-to-end with typed document classification over multi-model LLM pipelines. Independently, my InventoryReservationService is a Java 21 and Spring Boot API with PostgreSQL row-level locking, proven correct under concurrency with Testcontainers integration tests, so I can move comfortably in your core analytics language and your AI/ML integrations alike.
