    \item \textbf{Multi-LLM Provider Integration and Eval Frameworks:} \textbf{LLM Eval Harness} is a vendor-neutral Python evaluation system I built comparing Claude, GPT-4o, and Gemini across 2,000 frozen labeled examples --- hallucination rate, p50/p95 latency, cost-per-call, McNemar significance tests. The role calls out ``integrate with leading LLM providers and internal evaluation frameworks'' --- this is exactly what I built.

    \item \textbf{Production Observability and SLOs:} Across KubeServe and Isomer, I instrumented agent pipelines end-to-end with OpenTelemetry traces, Prometheus metrics, and Grafana dashboards. I have set up latency SLOs, tail behavior monitoring, and on-call playbooks for agentic systems.
