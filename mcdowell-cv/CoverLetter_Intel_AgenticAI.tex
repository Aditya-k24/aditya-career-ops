\begin{itemize}[leftmargin=*, itemsep=3pt, label={\color{IntelBlue}\faAngleRight}]

    \item \textbf{Multi-Model API Integration and Prompt Engineering:} At \textbf{Isomer AI}, I shipped production LLM pipelines integrating Claude (Anthropic), GPT-4o, and Gemini with tool-calling, RAG, and Temporal.io agentic workflows. \end{itemize}
