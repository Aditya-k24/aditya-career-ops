Eve is the right abstraction. Agents need what Next.js gave web apps: opinionated structure, a production runtime, and a DX that lets developers write only what is unique about their agent. I have built the core pieces Eve is assembling --- durable orchestration with Temporal.io, MCP server integrations, and multi-LLM routing --- and I want to help build the framework that makes them first-class primitives for every TypeScript developer.

\vspace{4pt}

\begin{itemize}[leftmargin=*, itemsep=3pt, label={\color{VercelBlack}\faAngleRight}]
    \item \textbf{Durable Execution and Async Workflow Orchestration:} At \textbf{Isomer AI}, I built production agentic pipelines on Temporal.io --- durable orchestration with workflow versioning (Draft$\to$Live$\to$Archived), checkpoint-based execution, retry logic, and failure recovery at 30+ customer deployments. In \textbf{AlgoPulse}, I built the same patterns at 2,000 async inference requests per second on Kafka + Temporal. This maps directly to Eve's Workflows runtime layer.

    \item \textbf{MCP Servers and Connections Layer:} At Isomer, I designed and shipped MCP servers in Python and TypeScript that expose customer-internal tools to LLM agents --- file I/O, browser automation via Playwright, and Tailscale VPN tunneling for secure internal access. Eve's connections layer (Vercel Connect / MCP endpoints) is exactly this architecture at framework scale.

    \item \textbf{TypeScript Ownership Across the Full Stack:} TypeScript is my primary language. At Isomer, I owned the entire product codebase: React + Node.js, Auth0 RBAC, PostgreSQL, Redis, Playwright test coverage. In \textbf{PulseRank}, I built a production event-driven system in NestJS and Next.js --- Vercel's own ecosystem. I write the kind of TypeScript APIs that developers actually want to use.

    \item \textbf{Multi-LLM Routing and Agent Evaluation:} Through \textbf{KubeServe} and Isomer, I built model-agnostic LLM routing across Claude, GPT-4o, and Gemini with circuit breakers and EWMA load balancing. I also built a vendor-neutral LLM eval harness --- 2,000 frozen test examples, hallucination rate, p50/p95 latency, McNemar significance tests --- which maps to Eve's evaluation and observability story.
\end{itemize}
